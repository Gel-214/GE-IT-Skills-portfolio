### The Davao Agro-Logistics Prompt System
#### 1. System Prompt Template (V3 – Final Optimized)
[Role] act as a digital solutions architect who is consulting for a local government unit in the Davao region
[Context] Most government communication offices use AI superficially, producing generic, Western-centric content. You must build a localized prompt framework that locks the AI into a specific geographic context (e.g., addressing agricultural logistics in Davao del Norte or eco-tourism in Samal) while maintaining a strict professional tone.
[Task] You are to engineer a highly specific text generation system prompt and an accompanying visual vector icon that establishes an operational workflow for an economic or social initiative in Mindanao.
[Constraints] generate images appropriate for the task, and import them into a Word document
[Output] You are tasked to create an interactive Markdown Prompt Playbook submitted to your GitHub Portfolio. It must contain:
1. A reusable system prompt template.
2. A "Prompt Battle Table" showing three iterations of improvement.
3. An AI-generated structural icon or visual asset designed using strict style constraints.
